## Jenkins - Freestyle Jobs

### 1. What is a Freestyle Job?

A Freestyle Job is one of the simplest types of Jenkins jobs.

It allows us to configure build tasks using the Jenkins web interface instead of defining the entire pipeline as code.

Freestyle Job
↓
Jenkins UI
↓
Configure Build Steps
↓
Execute Build
↓
View Result


### 2. How Freestyle Job Works

Developer
↓
GitHub
↓

↓
Freestyle Job
↓
Checkout Code

↓
Test
↓

↓
Result


### 3. Creating a Freestyle Job

Basic steps:

1. Open Jenkins.
2. Click "New Item".
3. Enter the job name.
4. Select "Freestyle project".
5. Click "OK".
6. Configure the job.
7. Save the configuration.
8. Click "Build Now".


### 4. Source Code Management

A Freestyle Job can connect to Git repositories.

Example:

GitHub Repository
↓
Jenkins
↓
Source Code Checkout


We can configure:

- Git repository URL
- Branch
- Credentials


### 5. Build Triggers

Build triggers determine when Jenkins should execute the job.

Common triggers:

- Build periodically
- Poll SCM
- GitHub webhook
- Manual build


Example:

Developer
↓
git push
↓
GitHub Webhook
↓
Jenkins
↓
Freestyle Job Starts


### 6. Build Steps

Build steps contain the commands Jenkins needs to execute.

Example:

```bash
mvn clean package
```

### 7. Post-build Actions
Post-build actions execute after the main build process.
Examples:
- Archive artifacts
- Send notifications
- Trigger another Jenkins job
- Publish test results

## 10. Freestyle Job vs Pipeline
    Freestyle Job:
- Configured mainly through Jenkins UI
- Simple to create
- Suitable for basic automation
- Configuration can become difficult to manage as complexity increases
  Pipeline:
- Defined as code
- Usually stored in a Jenkinsfile
- Supports complex CI/CD workflows
- Version controlled with Git
- Easier to review and reproduce

## 11. Simple Comparison
    Freestyle Job
    ↓
    Configure in Jenkins UI
    Pipeline
    ↓
    Write Jenkinsfile
    ↓
    Store in Git

## 12. Important Limitation
    Freestyle Jobs are useful for learning Jenkins basics and simple automation.
    For complex production CI/CD pipelines, Pipeline as Code is generally more suitable because the pipeline definition can be version controlled and reviewed.
## 13. Interview Definition
    A Jenkins Freestyle Job is a basic Jenkins project that allows users to configure source code, build triggers, build steps, and post-build actions through the Jenkins web interface.
